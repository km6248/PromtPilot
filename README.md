# PromptPilot — AI Prompt Analyzer & Optimizer

PromptPilot is a Flask web application that evaluates prompt structure and creates a clearer reusable prompt template.

## Features
- Explainable 0–100 prompt quality score across five checks
- Actionable suggestions for missing prompt elements
- Optimized prompt template
- Copy-to-clipboard support
- Responsive and keyboard-friendly interface
- JSON validation, request-size limits, and security headers
- Health-check endpoint for deployment monitoring

## Scoring
Each of the five checks is worth 20 points:
1. Clear task
2. Context
3. Specific details
4. Output format
5. Constraints

**Scoring is heuristic, not an AI-model judgment.** The score is a guide to prompt completeness and does not guarantee the quality of an AI model's answer.

## Technology
Python 3.11, Flask, Gunicorn, HTML, CSS, JavaScript, Docker.

## Run locally
```bash
python -m venv .venv
# Windows: .venv\Scripts\activate
# macOS/Linux: source .venv/bin/activate
pip install -r requirements.txt
python app.py
```
Open http://127.0.0.1:8080

## Run tests
```bash
python -m unittest -v
```

## Deploy to Google Cloud Run
1. Push this project folder to your public GitHub repository.
2. Install and authenticate the Google Cloud CLI.
3. Select a Google Cloud project and enable billing.
4. Enable Cloud Run and Cloud Build APIs.
5. From this project folder run:

```bash
gcloud run deploy promptpilot \
  --source . \
  --region asia-south1 \
  --allow-unauthenticated
```

6. After deployment succeeds, Cloud Run prints the public `https://...run.app` URL. Open it and test `/` and `/health`.

The live URL is generated by Google Cloud during deployment; it cannot be known before deployment.

## API
`POST /analyze` with JSON:
```json
{"prompt": "Explain photosynthesis for grade 8 in a 5-point bullet list."}
```

`GET /health` returns:
```json
{"status": "healthy"}
```

## Security notes
- Prompt length is limited to 5,000 characters and request body size is limited.
- The browser renders returned user-controlled text using `textContent` and DOM nodes, not HTML injection.
- Basic browser security headers are applied.
- Do not commit API keys or `.env` files. This version does not call an external AI provider and does not require an API key.
